# 👤 Profile Card

A clean and responsive **Profile Card** built using **HTML and CSS Flexbox**. This mini project was created as part of my frontend development practice to understand how Flexbox can be used to create well-structured and responsive layouts.

## ✨ Features

* 👤 Profile picture and personal information
* 🎓 BCA Graduate badge
* 📝 Short professional bio
* 💻 Skills section
* 📍 Location
* 🔗 GitHub, LinkedIn, and Gmail buttons
* ➕ Follow button
* 🎨 Gradient background
* 📱 Responsive design
* 📐 Flexbox-based layout

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox

## 📚 What I Learned

While building this project, I practiced:

* Using `display: flex`
* Aligning elements with `justify-content`
* Positioning elements with `align-items`
* Managing spacing using `gap`
* Creating flexible layouts
* Styling buttons and skill badges
* Building a responsive profile card

1. Clone this repository.
